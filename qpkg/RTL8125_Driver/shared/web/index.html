RTL8125 2.5GbE Ethernet Driver for QNAP

Version: 9.018.00
Kernel: 5.10.60 (arm64)
Architecture: aarch64

Description

Kernel driver for Realtek RTL8125 series 2.5 Gigabit Ethernet controllers with a PCI-Express interface, as fitted to the onboard 2.5GbE port of arm64 QNAP NAS systems such as the TS-433.

Features

  • ✓ 2.5 Gigabit Ethernet over PCI-Express
  • ✓ Newer than the r8125 shipped with QTS
  • ✓ Optimized for QNAP QuTS hero h5.x.x and QTS 4.x/5.x
  • ✓ No system reboot required - driver loads immediately after installation
  • ✓ Automatic loading at system boot
  • ✓ S5 Wake-on-LAN support

Supported Devices

  • RTL8125: 2.5 Gigabit PCIe Ethernet
  • RTL8125B: 2.5 Gigabit PCIe Ethernet
Note: The driver is loaded automatically after installation. It replaces the r8125 module shipped with QTS, so the 2.5GbE link drops briefly while the driver is swapped.

Verification

To verify the driver is loaded and working, connect via SSH and run:

# Check if driver is loaded
lsmod | grep r8125

# View driver information
modinfo r8125

# List network interfaces
ip link show
