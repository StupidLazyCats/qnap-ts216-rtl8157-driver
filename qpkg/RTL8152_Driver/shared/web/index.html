Realtek USB Ethernet Driver

Driver version: 2.20.1

Target: QNAP TS-216/TS-416 (TS-X16), QTS 5.2.0, kernel 5.10.60-qnap, aarch64

This package installs the Realtek r8152 USB Ethernet driver with support for RTL8152, RTL8153, RTL8155, RTL8156, and RTL8157 devices. RTL8157 uses USB ID 0bda:8157.

A QTS firmware update may change the kernel. Do not load this module unless its vermagic exactly matches the running kernel.

Verification

lsusb
lsmod | grep r8152
cat /sys/module/r8152/version
dmesg | grep -iE 'r8152|rtl8157'

The TS-216 USB 3.2 Gen 1 port has a raw 5 Gbps bus rate, so sustained 5GbE line rate is not expected.
